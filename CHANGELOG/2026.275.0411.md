## Summary

Bump `spec`/`sdk` past the schema gate that was degrading the `deploy:kubernetes` / `deploy:kindcluster` deploy key via this kubevirt provider. Fixes the producer leg of `opencharly/charly#738`.

## RCA

A `deploy:kindcluster` bed fails at its `deploy-add` step:

```
charly: error: command "deploy": ... preresolve substrate "kindcluster":
  ... <project>/charly.yml: schema 2026.261.1747 is required (found "").
  Run: charly migrate
```

Root cause: the schema-versioning-removal cutover deleted the load-time schema gate in `sdk v0.2026270.1147`. This plugin self-loads the project config, and its newest release still compiled against `sdk v0.2026268.1823`, so the retired gate rejected the current (unversioned) config. This is the `charly#733` cutover reaching this repo.
