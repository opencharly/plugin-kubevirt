## Summary of changes

- **`candy/plugin-kubevirt/charly.yml`** — three new sibling `skill:` nodes:
  - `kubevirt` (family `kubevirt`, category `kind`) — the 7th deploy substrate:
    `kind: kubevirt` templates + `kubevirt:`/`target: kubevirt` deploys, the
    VirtualMachine CR lifecycle (DataVolume, runStrategy, VMI Ready + AgentConnected,
    managed `virtctl port-forward` SSH), instancetype, snapshots, live migration, GPU
    host-device passthrough; the `charly kubevirt` CLI family; the `DeployTraits`.
  - `check-kubevirt` (category `commands`) — the declarative `kubevirt:` check verb
    (vm/vmi/wait-ready/printable-status/guest-info/datavolume/snapshot/migration/
    start-stop-restart/console/port-forward) + a `references/live-probe-verbs.md` split.
  - `kubevirt-operator` (category `commands`) — the KubeVirt + CDI platform install
    (`candy/kubevirt-operator`).
